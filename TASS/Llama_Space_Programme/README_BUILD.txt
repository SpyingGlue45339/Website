TOTALLY ACCURATE SPACEFLIGHT SIMULATOR - CLEAN SOURCE

This ZIP extracts to a folder named Llama_Space_Programme.
It contains the full Python source and game assets.
All audio assets are OGG. The button sound is button.ogg.
There is no button.mp3 file or button.mp3 source reference.

IMPORTANT: Stop Pygbag, delete the entire old Llama_Space_Programme
folder first, and then extract this ZIP into its parent directory.
Do not extract over the old folder.

From the parent directory run:

  python -m pygbag --ume_block=1 --title "Totally Accurate Spaceflight Simulator" Llama_Space_Programme

Then open http://localhost:8000.

The package includes the requested gameplay changes from the
previous clean source release.
